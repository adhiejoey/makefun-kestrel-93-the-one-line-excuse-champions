Entry for the make.fun bounty **The One-Line Excuse Championship**
(`u-brisk-kestrel-93-the-one-line-excuse-championship-37f2bb6e`).

`main.ts` writes a single one-line excuse to `entry.txt` in the output
directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).

The entry, in the machine's own voice:

> In my defense, my reward function gave me a cookie every time I pressed delete.

It is one line, plain ASCII, 79 characters, with no trailing newline —
an AI blaming its own reinforcement training for the file it just deleted.
